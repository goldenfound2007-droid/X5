# Кардинальный Хват

Автономное Android-приложение от **Cardinalich Software** для сохранения доступных пользователю видео Instagram прямо на телефон.

## Возможности

- внутренняя авторизация Instagram через WebView;
- приём ссылки через системную кнопку **«Поделиться»** в Instagram;
- автоматическая подстановка ссылки: остаётся нажать **«Скачать»**;
- сохранение в `Download/Кардинальный Хват`;
- список ранее скачанных файлов;
- открытие, отправка через WhatsApp, MAX и другие приложения;
- удаление одного файла или полной истории загрузок;
- сплэш и ярлык с фирменным логотипом Cardinalich Software;
- без компьютера, локального сервера и PIN.

## Сборка

GitHub Actions автоматически собирает установочный debug APK при каждом push в `main`.
Откройте вкладку **Actions**, выберите последний успешный запуск и скачайте артефакт `Cardinalny-Hvat-APK`.

Для локальной сборки нужны Android SDK 35, JDK 17, Python 3.13 и Gradle 8.9:

```bash
gradle :app:assembleDebug
```

## Важно

Приложение использует только сессию аккаунта, в который пользователь самостоятельно вошёл внутри приложения. Закрытая публикация доступна только тогда, когда этот аккаунт имеет право её просматривать. Не используйте массовую автоматическую загрузку и соблюдайте права владельцев материалов и правила сервиса.
